# MetaGene实验汇报：AI主动学习驱动的代谢—表观遗传跨维度合成致死候选筛选与奥沙利铂耐药逆转研究

报告更新时间：2026-11-02T16:13+08:00；数值实验完成时间：2026-10-30T16:06+08:00。本报告引用已完成的**137个基准拟合、20条12轮主动学习序列、5个最终候选模型**。运行设备：NVIDIA GeForce RTX 3090, NVIDIA GeForce RTX 3090。计算产物完整性检查通过10522项。

## 1. 研究目标与当前结论

本研究的核心问题是：代谢重编程与表观遗传重塑是否形成代偿关系，使双基因干预揭示单基因筛选不能发现的脆弱性，并在结直肠癌奥沙利铂耐药背景中恢复敏感性。计算侧负责提出、排序和解释这一假说；新实验与机制验证由医学院承担。

研究对象已严格限定为**代谢酶 × 直接组蛋白修饰酶**。现有898个建模基因包含38个严格代谢酶、15个直接组蛋白修饰酶，570对中19对已有HT29组合测量，剩余**551对核心候选**。由同一GNN评分形成**Top500→Top30→Priority8→3对首轮代表候选**。BRD3等reader、MEN1等辅因子和其他表观调控因子仅在扩展表中汇报。

主模型为 **Pooled / multi-graph**，由候选GNN架构在验证集上选择；全部方法中验证表现最好的方法为 **NAIAD reimpl.**。主GNN的未见配对测试Spearman为 **0.513 ± 0.007**，RMSE为 **0.125 ± 0.001**。该GNN未稳定优于全部基线，模型选择与泛化评价分别报告。

更严格的泛化结果需要优先注意：主GNN未见基因测试Spearman为 **-0.006 ± 0.026**，跨细胞迁移为 **-0.026 ± 0.006**，接近零的结果不支持可靠外推。这限制了Top500作为预测命中名单的证据强度；当前仅作为待检验假说目录与后续采集真实反馈的起点。

严格核心的已测空间仅19对，本次主测试包含3对，主动学习池包含10对。核心域的样本量不足限制了对新组合发现能力的评价；全量域性能不能替代该核心域的独立验证。**当前成果适合干实验阶段汇报与探索性候选交接，不证明已发现合成致死机制或逆转耐药。**

**交付判断：可用于计算阶段汇报与探索性候选交接；现有计算证据尚不足以支撑高可信耐药逆转候选的最终定稿。** 这里区分计算工作是否完成与候选是否获得足够支持，不将合作方尚未开展的新实验记作计算流程故障。

整合后每个基因有1831维特征，包含Reactome通路成员、严格功能标记、独立证据数值及显式缺失标记。连续特征的填补和标准化统计量在每个训练基因集合内估计；缺失标准化为0，并保留缺失指示。TCGA按患者汇总；单细胞先按全部基因UMI做CP10K与log1p，再在患者内、患者间汇总，避免细胞数多的患者主导。肿瘤组织中的上皮细胞沿用作者标签，不等同本项目重新鉴定的恶性细胞。

**通量输入。** [Herrmann等的原研究](https://doi.org/10.3390/cancers13164130)与[固定代码来源](https://github.com/HAHerrmann/Hct116_DrugRes)提供HCT116亲本/OxR热力学模型的上下界。对每个状态按其HCC_biomass下界归一化，取log1p最大绝对界，再按反应—基因映射等权汇总。共有4723个反应范围，192个反应映射到134个建模基因。这里重分析的是clean快照，未声称复现论文全部图；GPR成员关系未被当成敲除模拟。通量上下界也不是统计置信区间。

**表观图谱。** [GSE138654](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE138654)含H3K4me3、H3K27ac、H3K27me3在HCT116/HCT116OxR中的六个已处理峰表。使用hg19 RefGene各转录本TSS±2kb窗口并集，提取不重复峰数与最大富集。仅保留描述性状态差，不做无重复的差异结合检验；峰数及富集差异可能受样本与峰调用影响，没有跨样本spike-in校准。图谱不能指定某候选修饰酶的直接靶基因。该研究的耐药株、通量研究的耐药株与合作方的HCT116-R分别保留身份。

## 4. 建模与评估协议

训练来源及测量量：

| 来源 | 测量记录 |
| --- | --- |
| horlbeck_jurkat | 95266 |
| horlbeck_k562 | 100128 |
| ht29_colo1 | 15864 |

监督目标是来源标尺上的`GI = joint − single_a − single_b`。不同来源先用训练记录的均值和标准差做标准化；未知来源仅比较排序，不强行换算原始误差。该加性残差不是作者统计GI，也不是已验证SL标签。

HT29已测GI代理量中，99.01%低于0，中位数为-0.473。因此负值本身几乎没有筛选特异性。候选同时报告相对于HT29来源分布的经验百分位（不是P值）、已测single、重构joint与独立证据。两个独立预测头的代数不一致RMS为0.075；主GNN只学习GI，joint在具备两臂single时代数重构。

主GNN将独立基因特征映射到共享表示，对外部图做一跳传播并使用可学习门控；以两个基因表示的和、绝对差、逐元素积组成交换对称pair表示，再接细胞背景与GI回归头。它不消费HT29原筛选single值作为GI输入，因而能以同一预测器覆盖551对核心候选。NAIAD为适配本任务的重实现，线性、NAIAD、双头和XGBoost基线可使用已测single；因此跨类模型差异包含输入及结构差异，不作为纯图因果消融。

隐藏维度96，dropout 0.15，学习率0.001，batch 4096，最多100轮、早停耐心15。pooled训练平衡K562/Jurkat/HT29来源，权重为0.25/0.25/0.5。分割种子101；主训练种子[101, 211, 307, 419, 503]，次级协议种子[101, 211, 307]。随机种子SD主要反映优化随机性。

## 9. Top500、首轮代表组合与交接
